# Neon Drift

Arcade pseudo-3D racer with a Game Boy Advance look: 320x180 pixel art, synthwave 80s
roads, five tunable cars, nitro, air-thruster jumps and online rooms for up to 8 players.
Built with Godot 4.7.2 and GDScript. Code is MIT, art is CC-BY 4.0.

```
tools/agent.sh bootstrap   # link the engine, create .venv, import
tools/test.sh              # headless tests
tools/godot.sh             # run the game
```

See `docs/PLAN.md`, `docs/GDD.md` and `AGENTS.md`.
