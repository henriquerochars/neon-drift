# Licensing

Neon Drift is open source. Each part of the repository has one license.

| What | Where | License |
|---|---|---|
| Code, scenes, data resources, tests, tools, docs | everything not listed below | [MIT](LICENSE) |
| Art: sprites, backgrounds, UI, pixel font, VFX, README media | `art/`, `docs/media/` | [CC BY 4.0](art/LICENSE) |
| Music and sound effects | `audio/` | [CC BY 4.0](audio/LICENSE) |
| gdUnit4 test framework (third party) | `addons/gdUnit4/` | MIT, see [its license](addons/gdUnit4/LICENSE) |

**Attribution for CC BY 4.0 assets:** "Neon Drift art, Henrique Rocha Serrano, CC BY 4.0" (or
"Neon Drift audio" for sounds), with a link to this repository and to the license.

**Contributions** are accepted under the same terms: code you contribute is MIT, art and audio you
contribute are CC BY 4.0 (inbound = outbound). See [CONTRIBUTING.md](CONTRIBUTING.md).

**Exported builds** (`tools/build.sh`) ship `LICENSE`, `ART_LICENSE`, `AUDIO_LICENSE` and
[`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md), which carries the Godot Engine notice that
every distributed Godot game must include.

**Generated assets.** Art was generated with PixelLab under a paid subscription, whose terms let
the subscriber use and license their generations. Audio was synthesized by our own script. No
asset, name or code from another game is used.
